CS Browser Page Title - Changelog

All notable changes to CS Browser Page Title will be documented in this file.

The format is based on Keep a Changelog, and this project adheres to Semantic Versioning.

v1.0.0 2026-01-03

🚀 New Features

  • Initial Release: Joomla 5 system plugin to set browser page title from custom field value
  • Custom Field Selection: SQL-based dropdown to select any article custom field
    • Lists all published custom fields for articles
    • Easy configuration in plugin settings
  • Site Name Handling: Respects Joomla's global "Site Name in Page Titles" setting
    • Site name before page title
    • Site name after page title
    • No site name
  • Fallback Option: Configurable option to leave default title unchanged if custom field is empty
  • System Plugin Architecture: Uses onAfterRender event to modify final HTML output
    • Guarantees title changes are not overwritten by Joomla's article view
    • Fires after ALL rendering is complete
  • DatabaseAwareTrait: Direct database queries to fetch custom field values from #__fields_values table
